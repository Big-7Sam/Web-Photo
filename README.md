# Santiago Fotografia - Portfolio + Admin

Portfolio fotografico con estetica neon, selector ES/EN, galeria publica, lightbox y panel de administracion conectado a Supabase.

## Estructura

- `index.html`: sitio publico.
- `admin.html`: panel de administracion.
- `style.css`: estilos compartidos del sitio y admin.
- `app.js`: idioma, galeria publica, perfil, contacto y lightbox.
- `admin.js`: login, subida, edicion de categorias, perfil, contacto y estadisticas.
- `supabase.js`: configuracion del cliente Supabase.
- `photos export/`: fotos locales de referencia. La galeria publica carga desde Supabase.

## Setup de Supabase

1. Crea un proyecto en Supabase.
2. Copia `Project URL` y `anon public key` en `supabase.js`.
3. Crea las tablas con este SQL:

```sql
create table portfolio_images (
  id bigint generated by default as identity primary key,
  title text,
  category text,
  categories text[] default '{}',
  sort_order integer,
  is_featured boolean default false,
  image_url text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table profile (
  id bigint generated by default as identity primary key,
  bio text,
  bio_en text,
  profile_image text
);

create table settings (
  id bigint generated by default as identity primary key,
  email text,
  whatsapp text,
  location text,
  instagram text,
  contact_title text,
  contact_subtitle text,
  logo_text text
);
```

4. Crea un bucket de Storage llamado `portfolio`.
5. Configura Auth para el usuario administrador.
6. Revisa las politicas RLS segun tu hosting y nivel de privacidad.

Si ya tenias la tabla creada, agrega las columnas nuevas con:

```sql
alter table portfolio_images add column if not exists categories text[] default '{}';
alter table portfolio_images add column if not exists sort_order integer;
alter table portfolio_images add column if not exists is_featured boolean default false;
alter table profile add column if not exists bio_en text;
```

`sort_order` permite ordenar fotos desde el admin. `is_featured` permite marcar una foto destacada para usarla como fondo del hero.
`bio_en` permite cargar una biografia en ingles. Si queda vacia, la web muestra la biografia en español.

Las categorias viejas se mapean temporalmente asi:

- `Blanco y Negro` -> `Retratos`
- `Gothic` -> `Dark`
- `Urbano` -> `Dark`
- `Nocturno` -> `Dark`

Desde el admin podes abrir cada foto y guardar las categorias nuevas para que queden persistidas en Supabase.

## SEO basico

`index.html` incluye title, description, theme color y Open Graph/Twitter cards. Antes de publicar, conviene cambiar esos textos por el nombre definitivo, una descripcion real y, si queres que WhatsApp/Instagram muestren preview con imagen, agregar una etiqueta `og:image` con una URL publica.

## EmailJS

En `index.html`, reemplaza:

```js
emailjs.init('TU_PUBLIC_KEY');
window.EMAILJS_SERVICE_ID = 'TU_SERVICE_ID';
window.EMAILJS_TEMPLATE_ID = 'TU_TEMPLATE_ID';
```

Si no configuras EmailJS, el formulario se vera bien pero no enviara mensajes reales.

## Prueba local

Desde esta carpeta puedes servir la web con cualquier servidor estatico. Ejemplo:

```bash
python -m http.server 8080
```

Luego abre `http://127.0.0.1:8080/index.html`.
