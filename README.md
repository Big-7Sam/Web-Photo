# Santiago Fotografía — Portfolio + Admin

Portfolio fotográfico profesional con panel de administración usando Supabase.

## 🎨 Stack
- **Frontend**: HTML5, CSS3, JavaScript Vanilla
- **Backend**: Supabase (Auth + Database + Storage)
- **Hosting compatible**: Netlify, Vercel, GitHub Pages

## ⚡ Setup de Supabase (10 minutos)

### 1. Crear proyecto
- Ve a https://supabase.com/dashboard y crea un nuevo proyecto gratuito.
- Guarda tu **Project URL** y **anon public key** en *Settings → API*.

### 2. Crear tablas (Editor SQL)

```sql
-- portfolio_images
create table portfolio_images (
  id bigint generated by default as identity primary key,
  title text,
  category text,
  image_url text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- profile
create table profile (
  id bigint generated by default as identity primary key,
  bio text,
  profile_image text
);

-- settings
create table settings (
  id bigint generated by default as identity primary key,
  email text,
  whatsapp text,
  location text,
  instagram text
);
